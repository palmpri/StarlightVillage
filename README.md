# StarlightVillage
마인크래프트 별빛마을 클라이언트 관리

## 설치와 업데이트

[최신 클라이언트 설치 파일 다운로드](https://github.com/palmpri/StarlightVillage/releases/latest/download/StarlightVillage-Setup.exe)

1. Minecraft 게임과 공식 런처를 종료합니다.
2. 설치 파일을 실행합니다. 기존 사용자는 기존 별빛마을 설치 경로를 선택합니다.
3. 이후에는 **별빛마을 런처**를 실행하면 업데이트를 확인하고 필요한 파일을 내려받아 적용합니다.
4. 업데이트 완료 후 플레이를 누르고, 공식 런처의 **별빛마을** 프로필로 게임을 실행합니다.

0.20.1은 자동 업데이트 기능을 처음 설치하는 버전입니다. 이전 사용자는 이번 설치를 한 번 진행해야 합니다. 서버 게임 모드는 0.20.0을 유지하므로 기존 서버와 호환됩니다.

개인 모드·쉐이더·리소스팩·설정·저장 파일은 보존하며, 서버에서 관리하는 파일만 갱신합니다. 게임이 실행 중이면 먼저 종료하라는 안내를 표시합니다. 네트워크 오류나 검증 실패 시 기존 파일을 유지합니다.

현재 자동 업데이트는 같은 Minecraft·NeoForge 버전의 모드와 런처 갱신을 지원합니다. Minecraft·NeoForge 버전 자체가 바뀌면 전체 설치 파일을 사용합니다.

## 배포 구성

- 공개 저장소에는 배포 안내와 공개 검증키를 보관합니다.
- 실행 파일과 서명된 업데이트 목록은 [Releases](https://github.com/palmpri/StarlightVillage/releases)에 배포합니다.
- 업데이트 목록은 RSA-SHA256 서명과 각 파일의 SHA-256을 검증합니다.
- 월드·계정 정보·인증 토큰·개인 서명키는 포함하지 않습니다.
